# Sakhi women's health app

A women’s health app focused on tracking cycles, wellness, and supportive guidance.

## Overview

This project includes frontend and backend services for the Sakhi platform.

## Project Structure

- `mobile/` – Flutter mobile app
- `bend/` – Backend API
- `README.md` – Project overview

## Local Development

### Frontend

See the mobile app README for setup instructions.

### Backend

See the backend README in `bend/README.md` for API and environment setup.

## Deployment

The app is configured for deployment via Vercel and the backend can be run locally or in a hosted environment.
